# 按模型、Key 和当前分组查看用量

打开「用量统计」，确认统计时区，选择快捷范围或在日期范围组件中选择日期与分钟，点击「查询统计」。时区默认取浏览器当前时区，可以改为宿主部署时区；不会自动推测宿主配置

页面依次读取当前 Key 目录、所选范围的历史请求和聚合贡献，显示已读条数。可以暂停、继续或取消；切到其他标签页会在当前页读取结束后暂停，返回时手动继续。完成后展示三个区域，分组结果不使用前 100 项排行榜代替全部数据

## 统计范围与数值

- 包含开始时间，不包含结束时间，结束晚于查询开始时刻时截到该时刻；实际扫描范围始终显示在进度下方
- 原生请求按开始时间纳入，Token 与费用只汇总公开用量合同中成功的请求；失败、取消、未完成和运行中次数分别保留
- 输入 Token 已包含缓存读写，总 Token 不重复累加缓存。推理 Token 已包含在输出中，不再重复计入
- 数值缺失显示「未知」；部分记录缺字段时显示已知小计与「部分」，缓存读取占比缺少必要字段时保持未知
- 金额使用历史已记录费用，不按当前价格重算。上游回报、宿主估算、外部聚合贡献分别保留，币种不换算合并；金额排序按 USD，其他币种仍完整显示
- 原生成功请求费用缺失及无费用的正请求数聚合贡献计入未计价提示。聚合贡献的内部计价覆盖率无法从现有合同还原，不能据此认定所有外部请求均已完整计价

## 模型、Key 与分组

模型采用实际上游模型名称，缺失时沿用请求模型，同名模型按 Provider 区分。模型查看 Key 明细，Key 查看模型明细；模型明细同时保留已记录的客户端请求名称

Key 按唯一 ID 关联，名称只用于展示。目录读取后，本次查询沿用该批读取到的当前名称与分组关系；配置改名不会合并不同 Key。已删除 Key 保留 ID，缺少 Key 归属的外部数据独立展示

分组按本次读取的 Key 当前绑定关系归类，不代表请求发生时的历史分组。一个 Key 绑定多个组时，同一请求会进入各组，因此不能将组间数值直接相加。未绑定分组的全账号 Key 与已删除／缺少归属的 Key 分开显示。这里不是按实际选中账号的当前分组分摊费用

外部聚合贡献和用量调整一并读取，不生成虚构请求。没有 Key 或模型维度的贡献进入未归属项，不按名称推测归属；负贡献保留为修正。缺少终态分布的请求数保留为「终态未归属」

## 查看明细与导出

点击请求次数可展开成功、失败等结果分布。每个区域可搜索名称或 ID，按请求数、总 Token 或 USD 金额排序；点击「查看 Key」或「查看模型」打开交叉明细

「导出 CSV」导出该区域当前搜索和排序下的全部结果，不只导出当前页。交叉明细也可导出。Token 保留整数文本，金额按币种独立列出总额与来源，日期范围、统计时区和字段缺失计数随行保留。未知币种金额留空，不当成零；CSV 中可能被表格软件当作公式的文本会转为安全文本

## 数据覆盖与性能

只读取宿主仍保留的历史与聚合贡献，无法恢复已清理的明细，也不能从现有接口确认被清理数据的完整历史覆盖。分页不是跨调用事务；读取期间历史补写、修改或清理可能影响结果，适合固定时间段的手动核对，不作为供应商账单或精确结算账本

分页调用只读，不修改账号、Key 预算或宿主用量。响应未确认时继续同一步会回读已提交进度，不重复累加同一页；若读取失败可继续，汇总容量或金额表示范围超限时需缩小范围重新查询。未完成任务不展示为完整结果，不允许导出

临时任务保存在插件内存，最多两个，闲置 15 分钟后清理，重启后需重新查询。只保留模型与 Key 的聚合单元，不积存全部原始请求；模型与 Key 组合及展示分组各最多 20000 项，超过容量明确报错，不截断为完整结果。CSV 最大 8 MiB

宿主接口需求见 [Issue #592](https://github.com/zyycn/codex-proxy-rs/issues/592)。当前读取集中在 `src/statistics/source.rs`，后续在宿主补齐通用只读聚合接口后替换为更高效的查询方式，插件报表合同与页面无需重新设计
