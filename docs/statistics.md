# 按模型、Key 和历史路由分组查看用量

宿主升级到 CPR 3.40.0 后，打开「用量统计」，确认统计时区，使用现成日期时间范围组件选择到分钟，点击「查询统计」。默认取浏览器时区，可改为宿主部署时区，不推测宿主配置

页面先读取 Key、分组名称目录，再查询模型／Key 和路由分组聚合。进度显示已读聚合行数，全部结束后展示结果，不读取原始请求正文，也不以 Top 100 代替全部数据

## 时间、Token 与金额

- UTC 范围包含开始、不含结束，未来结束值截到开始查询的时刻；原生按请求开始时间、外部贡献按归属时间纳入
- 请求和用量资格沿用宿主的预热排除、恢复关联与完整交付规则。成功、失败、取消、未完成次数分别展示，其余归入「状态未细分」，不猜测运行中数量
- 输入已包含缓存读写，推理已包含在输出，总 Token 不重复累加。Token 缺失保持未知，部分覆盖标注「已知小计」
- 页面统一使用 M（百万），通常最多两位小数，小于 0.01 M 保留到单个 Token，悬停看完整整数。排序和 CSV 保留原始数值
- 原生 Token 覆盖以完整交付请求为分母，外部覆盖以贡献记录数为分母，只用于缺失项提示，不能混成请求覆盖百分比
- 金额来自历史投影，不按当前价格重算。保留原币种、原生费用、外部贡献金额。上游回报、宿主计算、不可用费用仅有原生请求覆盖数量，接口未提供各币种下这两类金额，不做拆分估算
- 「原生未计价请求」只表示宿主返回的原生费用不可用数量，外部贡献内部的计价覆盖率未知。金额排序比较 USD，不换汇

## 模型与 Key 共用一个快照

模型与 Key 从一次 `UsageGrouping::KeyModel` 完整聚合读取归并，同一实际模型跨 Provider 合并，不回退到客户端请求名称。模型名称、Key 名称只用于显示，分组仍由稳定身份区分；Key 内部 ID 不展示，已删除 Key 显示「已删除 Key」

Key 看模型、模型看 Key 使用同一缓存快照。原生缺失身份与外部未归属贡献分开。贡献仅缺另一维度时，仍计入其已知的模型或 Key，不因联合分组的未归属标记丢失已知归属

宿主聚合不返回客户端请求别名、各 Provider 拆分，本页不再额外扫描明细补造这些信息

## 分组使用请求时的路由事实

分组查询使用 `UsageGrouping::RoutingGroup`，不再按 Key 当前绑定关系推算。名称取本次目录，历史已删除组仍保留身份并显示「已删除分组」。无路由分组事实的原生请求与外部贡献分别展示，不推测它们原先属于哪个组

多组请求分别进入各组，因此不能直接相加；宿主全局总计只计算一次。带明确组 ID 的「查看 Key」另开筛选快照，返回匹配请求的 Key 用量，不将多组请求按比例摊分

当前合同没有「路由组为空」或「仅外部贡献」过滤条件，因此「未关联路由分组」和「外部贡献（未归属）」只展示汇总，不提供该组交叉按钮

## 快照、暂停与取消

一次宿主读取在同一只读快照中完整消费所有批次。模型／Key、路由分组及首次打开某组明细分别查询，不作为跨视图共同事务。页面仅在数据延迟时提示，完整观察信息保留在 CSV 中

统计反映快照内已发布投影，原始数据变化需经过宿主 Worker 才可见；保留或清理后的实际可见范围以投影元数据为准，不能据此恢复已删除历史或把结果当作供应商账单

读取句柄绑定当前管理父调用，不能留到下一次页面请求继续。暂停或切换标签在本次维度查询结束后生效；继续从下一个维度开始。失败时丢弃本维度未完成结果，继续会重新查询该维度。取消会通知当前读取并关闭句柄，已取消结果不导出

任务仅在插件内存保存，最多两个，闲置 15 分钟后清理；每次聚合最多 20000 行，超限明确失败，不截断。只缓存主报表和最近一个组明细，重开另一组会重新查询。重启后重新选择范围

## 明细与 CSV

点击请求数，在该行下方整行展开结果分布，不占用后面的数值列。搜索名称或内部身份，按请求数、Token 或 USD 金额排序；导出包含当前搜索和排序下的全部行，而非仅当前页

CSV 保留原始整数、未知值和缺失项数量，各币种独立列出总额、原生和贡献金额，缺失来源金额留空。时间范围、统计时区和观察元数据随行保留，可能被表格软件识别成公式的文本转为安全文本。单份 CSV 最大 8 MiB
