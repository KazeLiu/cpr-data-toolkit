# 用量统计实施记录

## 目标与范围

只修改插件，不修改宿主业务代码、数据库或预算。2.1 已交付临时扫描和统一时间组件；2.2 接入宿主 3.40.0 的公开聚合快照，保留 M 单位、隐藏 Key ID、整行展开及导出

## 数据与合同

- 2.2 使用锁定 SDK 的 `query_usage_statistics`，一次管理父调用内读完各维度全部聚合批次，不保存跨调用读取句柄
- 请求按开始时间、贡献按归属时间纳入左闭右开范围，统计资格遵循宿主预热、恢复及完整交付规则
- 名称取公开目录，分组改用请求当时的路由事实；模型／Key 共用 KeyModel 快照，路由分组独立快照，多组重叠不重复计入全局总计
- 日期组件使用 UI 0.8.0 的 `datetimerange`，支持分钟；统计时区显式选择，不从浏览器时区猜宿主配置
- 展示各表快照与投影观察信息，暂停在维度间生效，取消关闭本次读取，未完整结束不能导出
- 临时任务仅保存在内存，最多两个，闲置 15 分钟清理；只保存聚合单元，不缓存全部请求正文

## 实现顺序

1. #592 已由宿主 #599 补齐，3.40.0 提供正式 SDK 合同
2. 移除逐请求扫描与原等待注释，接入聚合读取、观察信息、取消和单组交叉缓存
3. 同步费用来源、模型与历史分组语义，以及未知 Token 和全局分母
4. 连同此前 UI 修复及出站 UA 取值修正发布 2.2
