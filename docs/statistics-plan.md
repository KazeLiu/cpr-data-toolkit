# 用量统计实现计划

## 目标与范围

只修改插件，新增「用量统计」标签页，提供模型、Key、当前 Key 分组三种汇总、交叉明细、排序、缺失数据提示和 CSV 导出。不修改宿主、数据库或预算。追加范围为统一「同步历史费用」的日期时间范围组件，并提交、推送、打包发布 2.1

## 数据与合同

- 复用锁定 SDK 的 `usage.records.list` 和 `usage.aggregates.list`，逐页读取选定时间范围，不使用 Top 100 诊断代替完整结果
- 请求按开始时间、聚合贡献按归属时间纳入左闭右开区间；Token 与费用沿用成功请求口径，外部贡献独立保留，不补造归属
- 当前 Key 名称和分组从公开管理列表读取，在一次扫描内冻结；多组绑定分别计入各组，未绑定和已删除／未归属单独展示
- 日期组件使用 UI 0.8.0 的 `datetimerange`，支持分钟；统计时区显式选择，不从浏览器时区猜宿主配置
- 扫描不是跨调用事务，只能覆盖宿主仍保留的事实；未完成、暂停、取消、失败和完成明确区分
- 临时任务仅保存在内存，最多两个，闲置 15 分钟清理；只保存聚合单元，不缓存全部请求正文

## 实现顺序

1. 提交宿主通用只读聚合接口需求，关联 #590；已提交 #592
2. 实现独立分页扫描、汇总与查询模块；以 #592 标注后续替换位置
3. 接入插件管理路由，新增前端 API、统计表格及分钟级范围控件
4. 同步用法与数据口径，核对取消、重复步骤、缺失数据、多币种、分组重叠和 CSV 文本安全
