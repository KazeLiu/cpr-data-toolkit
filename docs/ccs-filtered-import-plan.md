# CCS 筛选导入、时段覆盖与原生请求判重

## 目标与验收

来源时区默认 Asia/Shanghai；应用默认 Codex、可选全部；模型为展示字段的大小写不敏感包含匹配，默认 gpt；时间默认不限，按来源时区解释。后端在完整来源数据上同时过滤三个条件，表格与汇总保持同一口径。日聚合仅在整个来源日期被范围覆盖时纳入，保留源内去重与明细／日聚合覆盖校验

预览固定筛选、来源数据与变更计划，确认和分批继续使用同一快照。变更条件使未提交预览失效；已开始任务须继续或明确结束后再改变条件。无选中数据不写入也不清空旧贡献

同一来源记录保留原稳定键。覆盖按宿主贡献归属时间替换所选时段内当前 CCS 来源的全部旧贡献，再导入本次筛选结果；旧贡献清理不限应用和模型，也包括已无法从来源还原的旧记录。时段外贡献、CPR 原生请求和其他来源保留；时间全部留空表示本来源全部历史

原生判重仅处理可靠代理日志时间、成功已完成、完整且非全零 Token 的明细，按现有模型名称归一规则比较。CCS 记录时间对 CPR 完成时间 ±30 秒；缓存口径统一，双方有缓存量时比较。候选图中双方唯一对应才排除，每个 CPR ID 最多使用一次；歧义保留并列明原因。日聚合及已丢失原生明细的历史不推测重复量

预览列出筛选后条数、疑似重复排除、无法确认及原因、待导入条数、更新和清理贡献，并分页查看匹配来源、CPR ID、时间差和 Token。覆盖确认只说明来源、时段和覆盖范围，提供取消与覆盖并导入，不展示冲突清单

日期时间输入使用宿主 UI 库 0.5.0 的 ZDatePicker，提交来源时区的日期和分钟字符串，不转换为浏览器 UTC。开始与结束可独立选择或清空，保留单边范围；不引入最近 31 天限制

## 当前约束

- 工程 D:\code\cpr-data-toolkit；已有未提交的 0.6 实现，在其基础上增量修改，不整理其他功能
- SDK 固定 bad2a245（v3.29.4）；ListRecords 时间过滤实际使用 started_at，虽然返回 completed_at，但不能按完成时间有界查全更早开始的长请求
- 不全历史扫描、不借用宿主数据库或管理 HTTP 绕过 SDK，不将有限开始时间窗口当成完整候选集
- 用户确认只改插件，表单按 CCS 记录时间简单过滤；原生核对使用所选开始时段，未填边界用选中来源最早／最晚时间，向前后扩展 30 秒。范围外更早开始的长请求不推断重复，保留 SDK 缺口说明，不扩宿主
- 现有贡献键没有应用／粒度元数据；用户确认覆盖只按来源和时间，不以应用或模型限制旧贡献。宿主按 bucket_start_ms 归属整项贡献，日聚合旧贡献归属来源日期午夜，不自动摊分
- 不新增或运行测试，不主动启动应用；构建和打包沿用原会话授权，交付 Linux ARM64 和 x86_64

## 失败与恢复

任务在插件内存保留原稳定键、变更列表、筛选条件、展示快照及逐批进度；超时或断连后同一任务重放同一批，使用宿主覆盖合同避免累计。预览过期或进程重启后按同一来源标识重新核对；不执行旧条件写入，不清理所选时段外贡献
