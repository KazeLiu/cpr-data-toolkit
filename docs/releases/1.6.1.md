# CPR 数据工具箱 1.6.1

额度分享账号名称修复，要求 CPR **3.33.0 或更新的兼容版本**，继续使用 RPC v7

## 分享名称统一使用 CPR 账号管理名称

- 开启「账号名称」后，原生 OAuth、直连 API Key 和 CPR 转发账号统一使用当前 CPR 账号管理中的名称，不读取邮箱或个人资料昵称
- 转发 CPR 子账号快照时使用当前接入账号的名称，不沿用快照中的旧名称；同一接入账号的多条快照仍使用各自稳定 ID，不合并额度
- 账号改名后，下游下次成功查询即可取得新名称，无需在上游重新获取额度
- 关闭「账号名称」时仍显示匿名编号，账号和模型访问权限、模型列表与额度数据保持原有规则

若账号管理中的名称本身为「OpenAI 账号」，请先在账号管理中改成需要分享的名称，插件不会自动命名或修改宿主账号

## 安装

在分享方更新到 `v1.6.1`，下游刷新额度后显示新名称。仅更新接收方不能改写分享方提供的名称

提供 Linux ARM64、Linux x86_64 和 macOS ARM64 原生 `.tar.gz`、校验文件及 ZIP。ZIP 文件名保留完整版本 `1.6.1`，解压后向 CPR 上传 `.tar.gz`
