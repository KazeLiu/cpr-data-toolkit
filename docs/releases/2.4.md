# CPR 数据工具箱 2.4

内部版本 `2.4.0`，最低宿主 **CPR 3.40.0**，SDK、UI 与私有状态 schema 不变

## 更新 DeepSeek 钉选

- 跟进 ClinePassBridge `af2d5f0`：精确 1017 请求模型、仅允许 deepseek 的启用规则自动附加 inferenceRegion，筛除私有通道
- 原有规则无需重填，能力为空仍保留区域筛选；其他模型、多提供方与未命中请求不增加区域规则
- 来源与响应模型以实际上游回报为准，不把 only/has 或 HTTP 200 当作成功钉选的证明

## 查看上游返回详情

- 转换与钉选日志显示真实 Chat 响应模型、首段有效输出与总耗时
- 点击「详情」查看状态、已应用参数、结束原因、Token 用量和路由诊断 JSON
- 不恢复请求 ID 展示，不记录回答、推理、工具参数或凭据；只保留有界的结构化诊断字段，详情按需读取
- 日志仍仅存于内存，最多 200 条，每条诊断最多 32 KiB，重启或清空即释放

## 安装与验证

提供 Linux ARM64、Linux x86_64 与 macOS ARM64 包。原实例升级至 `v2.4.0`，不要卸载或清空状态。ZIP 解压后上传 `.tar.gz`，关闭并重新打开插件管理页加载资源

本次执行构建与安装包检查，不运行行为测试、不启动宿主或发送模型请求。真实来源、工具调用和页面交互由用户在目标宿主验收

上游来源及每日跟进基线见 [Cline 上游跟进](../cline-upstream-sync.md)
