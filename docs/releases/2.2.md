# CPR 数据工具箱 2.2

内部版本 `2.2.0`，最低宿主 **CPR 3.40.0**。SDK 与官方打包 CLI 锁定到正式版本提交 `789609dd53663b323e43567d2476f7f83b6b77a1`，沿用 RPC v7、UI 0.8.0，不修改状态 schema

## 聚合统计改由宿主完成

- 接入 #599 已实现的公开 `query_usage_statistics`，不再逐页拉取原始请求后汇总
- 模型与 Key 共用 KeyModel 聚合快照，路由分组使用请求时保存的分组事实，取代当前 Key 绑定关系
- 每张表显示快照、投影覆盖、延迟和代次；全部分批读取完成后才展示和导出
- 原生预热、恢复关联和完整交付资格与宿主一致。未知 Token 保持未知，费用按币种保留原生及外部贡献金额，不按当前价格重算
- 单次读取绑定管理父调用，暂停在维度查询之间生效；取消会关闭当前聚合读取。分组交叉明细另开快照，未关联分组与外部未归属项没有相应过滤合同，不显示交叉按钮

请求接口见 [Issue #592](https://github.com/zyycn/codex-proxy-rs/issues/592)，口径和限制见 [统计说明](../statistics.md)

## 统计显示修复

Token 使用 M，悬停查看完整整数；缺失字段标注「已知小计」。Key 隐藏内部 ID，点击请求次数在行下方整行展开结果，避免与后面的列重叠

## UA 在出站准备后改写

原生请求的「改写前 UA」现在取宿主已经生成的出站头，「改写后 UA」取内部出站准备及 UA 规则执行后的请求。准备失败不再显示伪造的改写后值。按出站模型匹配，重试分别记录

**升级后启用 `outbound` 绑定，并把本插件放在出站链最外层**，避免其他外层插件再次改写；原有 `request` 绑定继续用于下游模型权限。Cline 转换独立保留 UA 规则，不走原生画像链，也不生成此类出站日志

## 安装与验收

Linux ARM64、Linux x86_64、macOS ARM64 均提供原生包、摘要和 ZIP。ZIP 解压后上传 `.tar.gz`，GitHub 来源标签为 `v2.2.0`

先升级宿主，再在原插件实例更新，不卸载或清空状态。存在 Cline 转换账号时按安装说明停用并排空请求，配置确认后恢复；关闭再打开插件页面加载新资源

发行执行前端类型与生产构建、三个平台编译和官方 CLI 打包，核对包内容与架构。不新增或运行行为测试，不启动测试宿主；统计数值、布局及真实出站 UA 由用户在目标宿主验收
