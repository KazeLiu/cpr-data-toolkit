# CPR 数据工具箱 2.9

内部版本 `2.9.0`，要求 **CPR 3.40.0** 或更新的兼容版本。已有插件实例可直接升级，无需重填转换账号或钉选规则。

## Cline 接入

- 按实际顺序操作：**选择转换账号 → 模型列表替换 → 应用实例配置**。页面的「配置步骤」可展开查看，协议兼容范围不再占据主界面
- 打开列表替换即选用 ClinePass 官方目录，无需逐个勾选。应用配置后隐藏转换账号的原模型和 CPR 映射到这些模型的别名；其他账号的同名模型也会隐藏，已有白名单仍然生效
- 钉选规则的模型名称可从 ClinePass 目录选择或手填。已应用的区域参数可在日志详情查看

升级后如果只需要协议转换，保持列表替换关闭。需要替换时先开开关，再复制配置并到插件设置粘贴保存；首次配置绑定见 [安装说明](../installation.md)。

发行包支持 **Linux ARM64、Linux x86_64、macOS ARM64**。解压对应 ZIP，在原插件实例上传 `.tar.gz` 升级，不要卸载或清空状态。
