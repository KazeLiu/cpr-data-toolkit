# CPR 数据工具箱 1.3

RPC v6 稳定版本 `1.3.0`，适用于宿主 v3.32.0 等 RPC v6 环境。SDK 0.1.0 与打包 CLI 固定到[提交 `af6fc21d`](https://github.com/KazeLiu/codex-proxy-rs/commit/af6fc21d70540a92fe4d5695ce1a7e999a65e6a3)，middleware v6，不兼容 RPC v5 或 v7

## 缺少宿主接口时提示升级

- 上游额度页检查账号 HTTP、入口认证、账号/模型授权和原生额度接口，缺失时显示升级指引与「重新检查」，分别禁用查询或分享操作
- 后台暂停缺失接口对应的查询，不反复报告刷新失败；分享入口返回可读的升级指引，不暴露底层 RPC 错误
- 检查只发送缺少必填参数的接口识别请求，不读取真实凭据、写状态或访问上游
- API 导入、用量导入、手动调整、模型定价和模型 UA 定制不受额度接口缺失影响，保留 1.2 的私有状态 schema、凭据版本隔离和并发更新规则

正式宿主 v3.32.0 尚无这些额度接口，额度功能会提示暂不可用。需要完整额度功能时，可使用包含对应接口的 RPC v6 实验宿主，或升级到包含 [PR #525](https://github.com/zyycn/codex-proxy-rs/pull/525) 的 RPC v7 宿主并安装插件 1.4

## 安装

提供 Linux x86_64、Linux ARM64、macOS ARM64 的原生 `.tar.gz`、`.sha256` 和 ZIP，共 9 个附件；Linux 最低 glibc 2.17。ZIP 内包含原生包、校验文件与 `INSTALL.md`，向宿主上传解压后的 `.tar.gz`

GitHub 来源可填写标签 `v1.3.0`，无需允许预发行。RPC v7 适配包为 1.4；宿主正式发布 RPC v7 后再将该版本转正，1.3 继续供 RPC v6 使用

未运行自动化测试或启动宿主，实际安装、接口提示与业务路径由使用者验收
