# CPR 数据工具箱 1.3

稳定版本 `1.3.0`，使用 RPC v7、middleware v6，SDK 0.1.0 与打包 CLI 固定到[宿主提交 `1fcfc977`](https://github.com/KazeLiu/codex-proxy-rs/commit/1fcfc9771d2f15b6c45a60b55ce332b8b2065871)

## 适配新版宿主

- 使用新版账号 HTTP、入口身份验证与冻结权限查询合同，由 SDK 管理任务挂起、恢复与回调回收
- 分享模型按来源账号和上游模型逐项交给宿主授权检查，同一来源的重复模型复用本次查询结果，不把公开模型目录当作账号权限
- 查询、快照、分享设置仍由插件私有状态持有，保留 1.2 的状态 schema、版本比较、凭据版本隔离和失败处理；其他标签页功能不变

## 缺少接口时给出升级提示

上游额度页检查账号 HTTP、入口认证、授权和原生额度接口，缺失时显示升级指引及「重新检查」，分别禁用受影响的查询或分享操作，其他标签页仍可使用

检查只发送缺少必填参数的接口识别请求，不读取真实凭据、不写配置、不访问上游。后台遇到缺失的查询接口会暂停该功能，不反复报告后台刷新失败；直接调用分享入口也会返回可读的宿主升级指引，不输出底层 RPC 错误

## 安装要求

宿主必须支持 RPC v7。额度功能需包含 [PR #525](https://github.com/zyycn/codex-proxy-rs/pull/525) 的接口；RPC v6 及更早宿主不能启动本版本，不能靠修改安装包清单绕过协议要求。接口提示只适用于插件可以启动的宿主

提供 Linux x86_64、Linux ARM64、macOS ARM64 的原生 `.tar.gz`、官方 `.sha256` 和 ZIP，共 9 个附件。Linux 最低 glibc 2.17，没有 Windows 原生包。ZIP 内含原生包、校验文件和 `INSTALL.md`，向宿主上传解压后的 `.tar.gz`

GitHub 来源可填写标签 `v1.3.0`，无需开启预发行。1.2、1.1 等旧发行保留，不覆盖旧安装包

未运行自动化测试或启动目标宿主。实际安装、接口缺失提示、分享授权与真实上游查询由使用者验收
