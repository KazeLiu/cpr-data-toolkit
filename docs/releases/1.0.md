# CPR 数据工具箱 1.0

预发行版本 `1.0.0`，需要包含 [宿主 PR #505](https://github.com/zyycn/codex-proxy-rs/pull/505) 的宿主（能力版本 3.29.8）。正式版宿主 v3.29.7 继续使用插件 0.9。

## 上游额度

- 通过公开 SDK 配置 CPR、Kimi 国内/海外按量付费与编程订阅、DeepSeek、Sub2API 查询
- 宿主使用账号当前凭据和单账号代理查询与保存，沿用后台额度任务，关闭页面后仍会刷新
- 展示原生窗口、上游账号、已分享模型、原币种余额与明细，以及获取、尝试、错误和过期状态；未知值保持为空
- 查询设置使用凭据版本条件更新，不读取或重新提交 Key；冲突后重新读取

## 透传需要两端插件

上游与下游均安装并启用插件。上游为下游使用的 Client Key 启用 request 中间件绑定，在「上游额度 → 向下游分享额度」开启分享；名称和模型默认不分享。下游为接入上游的账号选择 CPR 查询。

插件响应 `/v1/quota`，宿主负责 Client Key 鉴权、账号范围、模型过滤及匿名标识。没有可用插件时返回 404，不提供原生透传兜底。认证或权限拒绝后停止下传旧快照，查询恢复后重新开放。

## 安装与构建来源

SDK 0.2.0 与官方打包 CLI 固定到已推送的 [宿主提交 `28799cc150c6d5fe8288d3d8a0d83ba99b1407cf`](https://github.com/KazeLiu/codex-proxy-rs/commit/28799cc150c6d5fe8288d3d8a0d83ba99b1407cf)，RPC v5。正式 Cargo 锁文件使用该 Git 来源，不依赖本地覆盖路径。

提供 Linux x86_64、Linux ARM64 和 macOS ARM64 包。Linux 最低 glibc 2.17；ZIP 内含原生 `.tar.gz`、校验文件与安装说明，解压后上传 `.tar.gz`，不要上传 ZIP。没有 Windows 正式包。

## 验证范围

Windows 隔离 A/B 环境已用 6 个模拟账号确认插件接管、停用后 404、恢复后透传，以及后台刷新、额度展示、模型列表和分享设置。前端完成类型检查、ESLint 与生产构建，插件与宿主完成本地构建。

未运行自动化测试；Linux/macOS 安装、真实上游账号和长时间并发行为尚未验收。
