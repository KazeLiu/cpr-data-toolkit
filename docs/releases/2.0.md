# CPR 数据工具箱 2.0

内部版本 `2.0.0`，要求 CPR 3.33.0 或更新的兼容版本，沿用固定 SDK、RPC v7 和 UI 0.8.0

## 移除插件 CPR 查询

- 「上游额度」不再提供 CPR 查询选项，并移除对应的网络请求与协议解析路径
- 已保存的 CPR 查询配置按「不查询」读取，不再后台刷新、展示或向下游转发旧快照
- 保留旧状态，`upstream_quota` 的 schema 与迁移合同不变；不修改账号凭据，不自动开启原生互联
- 保留 Kimi、DeepSeek、Sub2API、Command Code、Cline Pass 查询及「向下游分享额度」的 `/v1/quota` 出口

CPR 上游额度由宿主原生 CPR Link 提供。上游管理员需为连接使用的 Key 开启「CPR 互联」并选择分组；需要池内账号窗口时勾选「共享账号额度」。本机在宿主「账号管理」展开对应账号，查看「上游额度」。开启互联会将该 Key 的推理限制到分组内直连账号，建议使用独立互联 Key

保留的 `/v1/quota` 出口仍使用插件 `schemaVersion: 1` 协议，供旧版插件或兼容客户端读取；2.0 不再消费该协议，不替代宿主 `/v1/cpr/link`

## 安装与验收

发行平台为 Linux ARM64、Linux x86_64 和 macOS ARM64。ZIP 解压后上传 `.tar.gz`；宿主 GitHub 来源填写仓库 `KazeLiu/cpr-data-toolkit` 和标签 `v2.0.0`

在原实例上升级，不卸载或清空状态。存在 Cline 转换账号时，按安装说明先停用相关账号并排空请求，确认新实例配置及绑定后恢复。升级后关闭再打开插件管理页，加载新资源

发行流程执行前端类型检查、生产构建、三个目标平台编译和固定官方 CLI 打包。不新增或运行行为测试，不操作真实宿主；旧 CPR 配置停用及其他查询的实际行为由用户升级后验收
