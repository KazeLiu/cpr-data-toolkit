# CPR 数据工具箱 0.5

内部版本与 Git 标签为 `0.5.0` / `v0.5.0`，面向 Codex Proxy RS v3.26.1。

## 新增与改进

- **社区价目过滤**：models.dev 表格支持名称、模型 ID 或价格关键词筛选，「社区模型 ID」表头增加包含筛选。忽略大小写，两项条件组合生效，先筛选整个来源再分页，翻页保持已应用条件
- **价格同步弹窗**：入口位于「models.dev 社区价目」右侧，默认「只补全缺失费用」，也可选择「覆盖全部历史费用」。确认提示「上游接口未开放」，当前不修改历史费用
- **多应用 API 导入**：解析 CC Switch 完整手动 SQL 导出的 Claude、Codex 和 Gemini 连接，修正 Codex TOML 解析和正常 SQL 索引被拦截的问题。支持多选、跨页全选和批量接入 OpenAI Responses 兼容上游；相同 API 与 Key 只接入一次，名称不同时选择保留名称
- **查看与复制**：API 地址可一键复制，Key 默认隐藏，主动查看或复制时按需读取；明文不进入日志或浏览器持久存储
- **模型定价**：批量维护 CPR 全局价目，补齐表头全选，缓存价格缺失或留空按零处理，修正提交多余字段导致的 HTTP 400。社区价目可核对目标 Provider 和实际模型 ID 后写入
- **模型UA定制**：模型名包含匹配忽略大小写，首条启用规则生效，支持 UA 与可选 originator、version。匹配预览及安全验证以状态色块展示，实际请求日志显示时间、模型、规则及替换前后 UA
- **界面调整**：弹窗在页面上方显示，长内容在弹窗内滚动，表单与说明文字保留间距

## 安装与升级

- 最低宿主为 CPR **v3.26.1**，清单兼容范围为 `>=3.26.1, <4.0.0`，SDK 和官方打包 CLI 固定到提交 `5358de53ddd4bda529cb63c422fd5c6af070f9c9`
- 提供 **Linux x86_64、Linux ARM64、macOS ARM64** 的 `.tar.gz` 原生安装包、各自的 `.sha256` 校验文件，以及便于下载的 ZIP
- Linux 包需要 **glibc 2.17 或更高**，不能直接用于仅有 musl 的系统或容器；macOS 包用于 Apple Silicon，二进制声明最低 macOS 11.0
- 选择与 **CPR 宿主进程** 平台一致的包，在插件管理页安装并切换至新版本。ZIP 内含原生包、校验文件和安装说明，先解压，再上传其中的 **`.tar.gz`**，不要上传 ZIP
- UA 规则保存后，还需在宿主启用本插件 `middleware` 的 `request` 绑定；建议限定所需的 Client Key，空范围表示全局

## 功能边界

- API 导入保存账号，不自动验证来源地址是否兼容 Responses，也不改写 API 路径
- 用量导入、手动调整和历史费用同步的确认按钮均提示「上游接口未开放」，不会写入历史统计或费用。当前模型价目更新只影响后续估算
- 请求日志的替换前 UA 是插件入口头，替换后是插件交给宿主的头；安全验证到插件出口为止，不发送真实上游推理请求，最终出站头需在实际宿主配置下确认
- 日志在插件进程内存保留最近 200 条，重启清空，不保存认证头、Cookie、请求正文或 API Key
