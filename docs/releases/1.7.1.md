# CPR 数据工具箱 1.7.1

**升级提示：本版本遗漏上游额度状态迁移，从 1.6.1 原地升级会被宿主拒绝。请直接升级 [1.7.2](1.7.2.md)，不要卸载或清空原插件状态。**

要求 CPR **3.33.0 或更新的兼容版本**，使用 RPC v7、公开 SDK 0.1.0 和 middleware v6

## 界面修正

- 去掉复选框外层多余的框线，修复全局业务分组样式与组件库同名类的冲突；导入弹窗和用量核对分组保持原布局
- 「仅看已选」加宽并保持单行
- 下游模型权限的API密钥选择器与上游额度一致，只显示名称和停用状态，不附带 ID
- 功能标签统一为「下游模型权限」「API密钥导入」「CC-Switch用量导入」「用量调整」「模型批量定价」，页面与当前说明统一使用「API密钥」

## 本次一并交付

- **下游模型权限**：按API密钥设置模型白名单，过滤普通和 Codex 模型列表、模型详情及额度分享中的模型 ID，未授权模型请求返回 403；默认保持原有权限，启用后空白名单表示全部禁止
- **钉上游**：按账号与最终模型 ID 注入 Responses 路由字段，提供 DeepSeek 1017 预设，并观察上游明确回报的最终来源
- **Cline Pass 额度**：使用账号中的 Cline API密钥查询官方 `usage-limits`，显示 5 小时、周、月额度，每分钟后台检查刷新，不推测金额或账号模型目录
- 保留 1.6.1 的额度分享账号名称修复；未正式发布的 1.7 草稿由本版本替代

## 安装与使用

提供 Linux ARM64、Linux x86_64 和 macOS ARM64 原生 `.tar.gz`、官方校验文件及 ZIP，Linux 需要 glibc 2.17 或更高版本。ZIP 内含对应原生包、校验文件和 `INSTALL.md`，解压后向 CPR 上传 `.tar.gz`；通过 GitHub 来源安装时使用标签 `v1.7.1`

下游模型权限需启用 `request` 绑定，覆盖目标API密钥，账号范围留空，失败策略选择「拒绝请求」；白名单按下游模型 ID 精确匹配、区分大小写，不扩大宿主的分组授权。无法确认模型身份的受限请求会被拒绝，当前包括 multipart 图片编辑

钉上游需启用 `outbound` 绑定，查看实际来源还需 `attempt` 绑定；上游必须支持 Responses 及路由扩展字段。来源元数据缺失时显示未知，不把参数注入当作实际来源证明
