# CPR 数据工具箱 2.1

内部版本 `2.1.0`，要求 CPR 3.33.0 或更新的兼容版本，沿用固定 SDK、RPC v7 和 UI 0.8.0

## 新增用量统计

- 新增「用量统计」标签页，按模型、Key 和当前 Key 分组查看请求数、输入输出、缓存读写、总 Token 及费用
- 使用分钟级日期时间范围组件，支持统计时区、快捷范围、暂停继续、交叉明细、搜索排序和 CSV 导出
- 逐页读取宿主保留的请求与聚合贡献，不以 Top 100 排行代替全部数据；未知字段、部分小计和多币种费用分别保留
- 分组使用本次读取的 Key 当前绑定关系，不还原历史分组；多组绑定会重复计入各组，组间数值不能相加

完整统计口径与覆盖限制见 [统计说明](../statistics.md)。宿主聚合接口需求已提交 [Issue #592](https://github.com/zyycn/codex-proxy-rs/issues/592)，查询代码已标注后续替换位置，接口补齐后改用更高效的聚合查询

## 统一历史费用时间选择

「模型批量定价 → 价格同步」的「同步历史费用」改用一个日期时间范围组件，不再分成两个独立输入框，支持分钟选择。保留本机时区、结束时间不含和已开始任务锁定范围的规则，不改变费用同步方式

## 安装与验收

发行平台为 Linux ARM64、Linux x86_64 和 macOS ARM64。ZIP 解压后上传 `.tar.gz`；宿主 GitHub 来源填写仓库 `KazeLiu/cpr-data-toolkit` 和标签 `v2.1.0`

在原实例上升级，不卸载或清空状态。存在 Cline 转换账号时，按安装说明先停用相关账号并排空请求，确认新实例配置及绑定后恢复。升级后关闭再打开插件管理页，加载新资源

发行流程执行前端类型检查、生产构建、三个目标平台编译和固定官方 CLI 打包，不新增或运行行为测试。统计数值、暂停继续、导出及历史费用同步的实际效果需在目标宿主验收
