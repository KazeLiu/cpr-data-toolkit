# CPR 数据工具箱 3.1

适配 CPR 3.51.0 起使用的 `scheduler` v4。公开 SDK 和打包 CLI 固定到 [CPR v3.54.4](https://github.com/zyycn/codex-proxy-rs/releases/tag/v3.54.4)，仍使用 RPC v7。

模型上游优先级通过 SDK 接收新版候选账号字段，继续按已保存的顺序从宿主允许且本轮可用的候选中选择。未命中规则或列表中没有可用账号时，仍由宿主调度。插件配置、绑定和私有状态 schema 保持不变。

在 CPR **3.51.0 或更新的兼容版本**中，从原插件实例升级至 `v3.1.0`。GitHub 来源使用 `KazeLiu/cpr-data-toolkit`；手动安装请上传对应宿主平台的 `.tar.gz`，不要卸载旧实例或清空状态。

提供 Linux ARM64、Linux x86_64 和 macOS ARM64 安装包。目标宿主上的实例升级和实际选号待安装后确认。
