# CPR 数据工具箱 3.0

内部版本 `3.0.0`，最低宿主 **CPR 3.40.0**，SDK、UI 依赖与私有状态 schema 不变。

## Cline 已停止接受客户端钉选参数

[ClinePassBridge v0.4.7](https://github.com/xiao-qiu-qiu/ClinePassBridge/releases/tag/v0.4.7) 报告 Cline 当前拒绝 `providerOptions`，旧的提供方、能力和区域参数会触发特定 403。

3.0 精确识别该拒绝，在下游错误和日志详情中提示停用规则及移除客户端参数。它被分类为参数错误，不再混同凭据失效；普通权限 403 保持原处理。新规则默认关闭，已有规则、启用状态和账号权限不自动改变。

如果接受自动选路，在「Cline 接入 → DeepSeek 钉选」编辑对应规则，关闭「启用规则」后保存，并移除客户端的 `provider` / `providerOptions`。此变更即时影响后续请求，无需重新复制实例配置。

**自动选路可能进入私有通道，无法保证固定 DeepSeek 官方**。插件不在拒绝后悄悄删除参数或重发请求，未使用真实凭据或发送模型请求验证。

发行包支持 Linux ARM64、Linux x86_64、macOS ARM64。在原插件实例上传对应 `.tar.gz` 升级，不要卸载或清空状态。
