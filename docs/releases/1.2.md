# CPR 数据工具箱 1.2

预发行版本 `1.2.0`，使用 RPC v6 和 middleware v6，不兼容 RPC v5。需要包含[宿主 PR #525](https://github.com/zyycn/codex-proxy-rs/pull/525)通用接口的宿主；正式版 v3.32.0 尚不包含这些接口

## 额度业务由插件维护

- CPR、Kimi 国内/海外按量与编程订阅、DeepSeek、Sub2API、Command Code 查询协议全部由插件实现
- 查询设置、展示快照、失败状态与分享开关保存在 `host.state` 私有状态，后台刷新通过 `maintenance` 执行，页面关闭后仍可刷新
- 网络请求使用账号当前代理和精确凭据版本，凭据只在后端二进制 RPC 中传递，不进入页面、私有状态或日志
- 保留同一凭据与查询类型的可用旧快照；401/403 停止下传，成功后恢复。版本比较隔离并发设置和迟到结果
- 沿用聚合额度卡片、模型搜索复制、原币种余额、CCS 导入、统计维护、模型定价和 UA 定制页面

## 分享入口与升级

`/v1/quota` 由插件 HTTP 中间件提供。宿主只提供账号受管 HTTP、入口身份验证、有效账号/模型授权与原生额度事实，不增加额度业务表、专属字段或刷新任务

向下游分享时，上下游均需安装本插件。上游启用无 Key、账号或模型范围限制的 `http` 绑定，再为下游使用的 API 秘钥开启分享；身份与账号/模型范围由插件调用宿主接口核对，名称和模型默认不分享

使用过 #505 实验宿主的环境应保留原分支和实验数据库备份，不把实验迁移套到主线数据库；查询与分享设置需在插件中重新配置。1.0/1.1 的 RPC v5 安装包不能通过改清单用于 RPC v6 宿主

## 安装包与来源

SDK 0.1.0 与官方打包 CLI 固定到[宿主提交 `af6fc21d`](https://github.com/KazeLiu/codex-proxy-rs/commit/af6fc21d70540a92fe4d5695ce1a7e999a65e6a3)。提供 Linux x86_64、Linux ARM64、macOS ARM64 三个平台的 `.tar.gz`、`.sha256` 和 ZIP；Linux 最低 glibc 2.17，没有 Windows 原生包。ZIP 内含原生包、校验文件与 `INSTALL.md`，向宿主上传解压后的 `.tar.gz`

通过 GitHub 来源安装需明确填写标签 `v1.2.0` 并允许预发行。稳定发行仍为 0.9，不用预发行覆盖最新稳定版
