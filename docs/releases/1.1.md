# CPR 数据工具箱 1.1

预发行版本 `1.1.0`，需要包含 [宿主 PR #505](https://github.com/zyycn/codex-proxy-rs/pull/505) 的宿主（能力版本 3.30.1）。正式版宿主 v3.30.0 尚不包含额度 SDK，继续使用插件 0.9。

## 额度详情

- 上游额度页调整为默认聚合的三列卡片，统一显示已用百分比；卡片按行等高，超出部分内部滚动
- 打开页面时刷新一次，保持查看时每三分钟刷新；切换窗口或标签不补刷
- 模型详情使用可搜索弹窗，模型名称可点击复制；直连上游取得的模型目录随额度快照保存，再按账号白名单、API 秘钥范围和分享设置过滤
- 保存查询设置后等待宿主首次查询结果，新账号无需再手动点击刷新

## Command Code

- 查询官方 `/alpha` 身份、credits、订阅和用量接口
- 展示五小时、周、月三项已用百分比，与宿主账号管理口径一致
- 月额度沿用 CC Switch 的账期池计算，不展示 credits 与费用明细

## 分享与命名

- 「宿主账号」改为「上游账号」，「Client Key」改为「API 秘钥」，「剩余额度」改为「额度详情」
- 分享栏将 API 秘钥选择、三个开关和操作按钮放在同一行；窄屏自动换行
- 聚合卡片标记来源账号；关闭聚合后通过下拉框选择上游账号

## 安装与构建来源

SDK 0.2.0 与官方打包 CLI 固定到已推送的 [宿主提交 `b3f00b4e654496d4cfee5577b47b2af157045e83`](https://github.com/KazeLiu/codex-proxy-rs/commit/b3f00b4e654496d4cfee5577b47b2af157045e83)，RPC v5。提供 Linux x86_64、Linux ARM64 和 macOS ARM64 包；Linux 最低 glibc 2.17，没有 Windows 正式包。

未运行自动化测试；页面交互和真实上游结果由使用者验收。
