# CPR 数据工具箱 1.5

支持 CPR **3.33.0 或更新的兼容版本**，使用 RPC v7。SDK 0.1.0 与打包 CLI 固定到 CPR v3.33.0 的提交 `8c8618aa0f841638262262e3338c115bc075f125`

## 模型上游优先级与顺序备用

新增「模型上游优先级」标签页。选择 Provider，输入完整上游模型名称，获取提供同名模型的账号；拖拽或使用上移／下移设置顺序，第一位首选，其余依次备用

在宿主启用本插件的 `scheduler` 绑定，并选择需要生效的 Client Key 范围。插件只选择宿主当前允许且可用的候选，首选不可用时按顺序选择备用；列表外的合法账号默认仍可备用。如果不希望某账号承接该模型，请在「账号管理」将该模型加入黑名单

宿主权限、账号状态、冷却、续写固定账号和重试安全规则继续生效；不对已输出的流无条件重发。规则按 Provider 和完整上游模型 ID 精确匹配，区分大小写

## 最近请求对照实际走向

启用 `observer` 的 `request_completed` 绑定后，发送模型请求，在「最近请求」点击「刷新日志」。表格显示各次尝试的插件选择、宿主报告的最终上游、请求结果和尝试次数，标注首选匹配、备用匹配、未命中规则或选择不一致等状态

最终上游只取完成事件；尚未收到时显示等待。事件为有界投递，缺失时可用请求 ID 对照宿主记录。日志只在内存保留最近 200 条，每页 25 条，每条最多保留最近 32 次选择，重启或主动清空后释放，不记录凭据和请求正文

## 安装

- GitHub 来源：仓库 `KazeLiu/cpr-data-toolkit`，标签 `v1.5.0`
- 提供 Linux ARM64、Linux x86_64 和 macOS ARM64 三个平台，共 9 个附件
- ZIP 包含原生 `.tar.gz`、官方 `.sha256` 和安装说明；上传解压后的 `.tar.gz`，不要直接上传 ZIP
- 旧版本安装附件不再提供，源码与 Git 标签保留；不兼容 RPC v6 及更早宿主，没有 Windows 正式包

三平台构建与打包通过 GitHub Actions 执行。未运行自动化测试，真实上游的首选命中和断连备用切换由使用者验收
