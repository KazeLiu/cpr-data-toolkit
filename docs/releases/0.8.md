# CPR 数据工具箱 0.8

内部版本 `0.8.0`，最低宿主 CPR v3.29.0。SDK 和官方打包 CLI 固定到 v3.29.4，UI 库升级到 0.5.0，固定提交 `5dec2c78fba37ee1f4c5007e4a0316837a72655a`

## 相比 0.5 的新增功能

- CCS Token 用量导入接通原生统计，支持应用、模型和来源时间筛选、分页预览、原生请求疑似重复核对及分批继续
- 手动 Token／请求数调整真实写入，结果未确认时保留原操作 ID 继续核对
- 历史费用可按时间与 Provider 补全缺失值或覆盖 Token 估算费用

## 覆盖所选时间段的 CCS 用量

点击「预览导入变更」，核对来源和时段，在简短确认框中点击「覆盖并导入」

- 替换所选时段内当前 CCS 来源的全部旧贡献，不限旧贡献的应用和模型，再导入本次筛选结果
- 不再因旧贡献无法还原来源记录身份而阻断日聚合导入，不展示冲突清单；原生疑似重复记录仍可按需查看
- 按宿主贡献归属时间判断覆盖范围，包含开始、不包含结束；旧日聚合整体归属来源日期午夜，不拆分
- 时间全部留空表示当前来源的全部历史；没有符合筛选条件的新数据时不导入，也不清理
- 保留时段外贡献、CPR 原生请求和其他来源；内容未变的贡献不重复写入
- 预览固定变更计划，沿用每批 100 项、暂停与同任务继续；跨批次不是事务，中断期间总量可能暂时不完整

## 宿主同款日期时间选择器

用量导入使用 `ZDatePicker` 替换浏览器原生日期输入，开始与结束可独立选择、输入或清空，保留单边时间范围和不限时间。按来源时区提交日期和分钟字符串，不转换为浏览器 UTC，也不限制最近 31 天

## 安装与验收

提供 Linux ARM64 与 Linux x86_64 安装包，需要 glibc 2.17 或更高。ZIP 内含原生 `.tar.gz`、官方 `.sha256` 和 `INSTALL.md`，解压后向 CPR 上传 `.tar.gz`，不要上传 ZIP。本地产物位于 `dist/0.8/`，旧版产物保留

前端类型检查与生产构建、两个 Linux 目标 release 构建和固定 CLI 打包通过。包检查确认版本 0.8.0、最低宿主、ELF 架构、glibc 2.17、后端执行权限和三份页面资源正确，ZIP 内含对应原生包、官方校验文件与安装说明，CRC 检查通过。链接器提示忽略已弃用的优化设置 `1`，不影响构建产物
