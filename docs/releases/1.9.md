# CPR 数据工具箱 1.9

内部版本 `1.9.0`，后端仍使用 CPR 3.33.0 的固定 SDK 与 RPC v7。保留全部业务功能、实例配置和状态 schema

## 修复新版 CPR 中的样式丢失

- UI 库升级到官方发布的 0.8.0 安装包，并提交固定依赖锁文件
- 使用官方 `themePrefix: 'cp'` 构建选项生成页面主题前缀声明，使新版宿主将语义 Token 注入为插件所需的 `--cp-*` 变量；旧宿主的变量前缀保持不变
- 自定义 CSS、utility 和弹窗选择器同步使用新版 UI 命名，继续跟随宿主配色与明暗模式
- 不修改账号、额度查询、用量、Cline 转换、钉选规则或插件私有状态

新版 CPR 的主题桥默认使用 `z` 前缀，缺少前缀声明的旧插件仍引用 `--cp-*`，导致按钮、表单、卡片及额度进度条的颜色、尺寸和边框失效。接入依据为 [UI 0.8.0 主题指南](https://github.com/zyycn/codex-proxy-ui/blob/d6100447010715c1203e67a4195fc6d875ff6249/playground/guide/theme.md)和 [CPR 3.38.1 主题桥](https://github.com/zyycn/codex-proxy-rs/blob/v3.38.1/frontend/src/views/plugins/management/bridge-runtime.ts)

## 安装与验收

从本版本 Release 选择 Linux ARM64、Linux x86_64 或 macOS ARM64 附件。ZIP 解压后上传 `.tar.gz`；也可在宿主 GitHub 来源填写仓库 `KazeLiu/cpr-data-toolkit` 与标签 `v1.9.0`

在原实例上升级，不卸载或清空状态。存在 Cline 转换账号时，按安装说明先停用相关账号并排空请求，确认升级后的配置与绑定后恢复。升级后关闭再打开插件管理页，加载新资源

发行构建执行前端类型检查、生产构建及三个目标平台编译，使用锁定的官方 CLI 打包。发布前检查包内主题前缀声明、CSS 变量、版本、资源和架构

未新增或运行行为测试，也未操作真实宿主；页面实际显示及明暗切换由用户升级后验收
