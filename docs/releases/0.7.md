# CPR 数据工具箱 0.7

内部版本 `0.7.0`，最低宿主 CPR v3.29.0。SDK 和官方打包 CLI 固定到 v3.29.4

## 筛选后导入 CCS 用量

- 来源时区默认 `Asia/Shanghai`，应用默认 Codex、可选全部，模型默认包含 `gpt`，忽略大小写；时间默认不限，填写后按来源时区解释
- 在完整来源上筛选，再分页、汇总与生成不可变导入预览；修改条件后重新预览，已开始任务须继续或明确结束
- 仅同步选中的来源记录与可靠归属的旧贡献，范围外及无法确认归属的旧键保留；没有选中数据时不写入或清空旧贡献
- 代理明细可核对 CPR 原生请求的疑似重复，模型、Token 与完成时间须符合条件，只有双方唯一对应时排除；可查看双方 ID、时间差及 Token
- 保留稳定记录键、每批 100 项与断线续传，不修改 CPR 原生请求或 Key 预算

## 判重边界

当前公开 SDK 按原生请求开始时间查询。插件对选中 CCS 时间范围向前后各扩展 30 秒，并按实际完成时间比较，不扫描更早历史；查询范围外更早开始的长请求、会话日志、日聚合、未知或全零 Token 及多候选保留，不推断重复量。完整规则见 README「疑似重复的范围与限制」

## 安装

Linux ARM64 与 Linux x86_64 安装包位于 `dist/0.7/`，ZIP 内含原生 `.tar.gz`、官方 `.sha256` 和 `INSTALL.md`。解压 ZIP 后上传 `.tar.gz`，不上传 ZIP。旧的 `dist/0.6/` 保留，不含本次筛选与判重功能

前端类型检查与生产构建、两个 Linux 目标 release 构建和固定 CLI 打包通过。已核对包内版本、实际 ELF 架构、glibc 2.17、执行权限、页面资源与 ZIP CRC；未运行行为测试、浏览器交互或真实导入，安装后的数据与交互效果由用户确认
