# CPR 数据工具箱 1.7.2

修复从 **1.6.1 升级时提示「插件状态版本不兼容或已发生并发变更」** 的问题，要求 CPR **3.33.0 或更新的兼容版本**，继续使用 RPC v7

## 修复状态升级兼容

1.7.1 在 `upstream_quota` 状态 schema 中增加 `cline_pass` 查询类型，但仍声明 schema 1 且没有迁移路径。宿主同时核对 schema 版本和结构，因此拒绝带旧状态的原地升级

- 将该命名空间的 schema 版本升为 2，并声明 `migratesFrom: [1]`
- 注册 SDK 的类型化状态迁移处理器，为宿主提供的每条记录返回 `Keep`，保留原键和值，不改写查询设置、额度快照或凭据版本字段
- 同步状态读取版本检查，其他命名空间继续使用原 schema；对外 `/v1/quota` 仍使用 `schemaVersion: 1`
- 同时支持 1.6.1 的旧查询类型和已安装 1.7.1 的 Cline Pass 状态迁移；未支持的迁移路径明确拒绝

## 升级方式

在原插件实例上直接升级到 `v1.7.2`，不需要卸载、清空配置或手动修改数据库。升级前保留常规宿主备份，升级后重新打开插件管理页。记录版本、迁移校验与最终状态提交由宿主管理

包含 1.7.1 的全部功能和界面修正，提供 Linux ARM64、Linux x86_64、macOS ARM64 的 `.tar.gz`、校验文件和 ZIP。ZIP 解压后向 CPR 上传其中的 `.tar.gz`；通过 GitHub 来源安装时使用标签 `v1.7.2`

## 验证范围

按锁定宿主的升级合同核对迁移声明、类型化处理器、状态读取及新旧包 schema，执行前端生产构建、三平台 Release 构建、官方 CLI 打包和安装包内容核对。按本次协作约定不新增或运行自动化测试；线上真实实例的原地升级和业务功能仍需用户验收
