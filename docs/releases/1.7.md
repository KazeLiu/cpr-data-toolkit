# CPR 数据工具箱 1.7

内部版本 `1.7.0`，要求 CPR **3.33.0 或更新的兼容版本**，继续使用 RPC v7、公开 SDK 0.1.0 和 middleware v6

## 下游模型权限

- 选择API密钥、获取模型列表并勾选允许的模型，过滤普通与 Codex 模型列表、模型详情和额度分享中的模型 ID
- 未授权模型请求返回 403，不进入上游；默认不限制原有API密钥，关闭限制恢复宿主原有权限，启用后空白名单表示全部禁止
- 使用宿主 `request` 绑定，API密钥范围留空或包含目标API密钥、账号范围留空，失败策略选择「拒绝请求」
- 按下游模型 ID 精确匹配，不扩大分组权限；受限API密钥无法确认模型身份时拒绝请求，当前包括 multipart 图片编辑

## 钉上游与 Cline Pass 额度

- 按账号及最终上游模型 ID 配置 Cline 提供方和能力过滤，提供 DeepSeek 1017 预设；通过 `outbound` 注入 Responses 路由字段，通过 `attempt` 观察上游明确回报的最终来源
- Cline Pass 查询使用账号中的 Cline API密钥访问官方 `usage-limits`，显示 5 小时、周、月的已用比例和重置时间，每分钟后台检查刷新，不推测金额或账号模型目录
- 保留 1.6.1 的额度分享名称修复，名称取当前 CPR 账号管理中的名称

## 统一页面名称

- 下游模型权限、API密钥导入、CC-Switch用量导入、用量调整、模型批量定价
- 页面字段、提示、错误消息和当前使用说明统一使用「API密钥」，修正「秘钥」写法
- 仅调整展示文案，保留原有 API 路径、字段名及私有状态命名空间

## 安装与验证范围

提供 Linux ARM64、Linux x86_64 和 macOS ARM64 原生 `.tar.gz`、官方校验文件及 ZIP，Linux 需要 glibc 2.17 或更高版本。ZIP 内含对应原生包、校验文件和 `INSTALL.md`，解压后向 CPR 上传 `.tar.gz`

发行流程执行前端类型检查及生产构建、三个目标的 Release 构建和官方 CLI 打包，不额外运行自动化测试。目标宿主安装、真实API密钥权限、额度查询及 Responses 上游对路由字段的执行仍需实际验收；来源元数据缺失时显示未知，不将参数注入当作实际来源证明
