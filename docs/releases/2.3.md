# CPR 数据工具箱 2.3

内部版本 `2.3.0`，最低宿主 **CPR 3.40.0**。沿用 RPC v7、锁定的 SDK 与 UI 0.8.0，配置、权限、接口和状态 schema 不变

## 全部页面沿用宿主视觉风格

- 公共导航改为中性选中态，保留十个标签入口与键盘切换，精简页头副标题
- 统一标题、表单间距、控件高度、按钮主次、圆角、分页和窄屏布局，继续跟随宿主主题
- 上游额度突出可用余额，赠送、充值余额及更新时间作为次级信息，查询设置与保存操作靠近
- Cline 接入按选择账号、加入转换配置、复制并应用配置排列，保留协议说明和兼容性限制，压缩提示与空状态
- API密钥导入、CC-Switch用量导入、用量调整、模型批量定价、模型UA定制、模型上游优先级、下游模型权限和用量统计分别调整表单、工具栏、表格及汇总层级
- 删除重复界面说明，保留必要的错误、覆盖确认和权限风险提示，多币种统计费用分行显示

## 安装

提供 Linux ARM64、Linux x86_64 和 macOS ARM64 安装包。ZIP 解压后在 CPR 上传 `.tar.gz`，GitHub 来源标签为 `v2.3.0`

在原插件实例升级，不卸载或清空状态，关闭再打开插件页面加载新资源。Cline 转换账号的停用、排空请求与恢复顺序见 [安装说明](../installation.md)

构建与打包不包含行为测试，不启动测试宿主。页面实际渲染和业务操作由用户在目标宿主验收
