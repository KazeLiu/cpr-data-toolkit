# CPR 数据工具箱 1.6

版本 `1.6.0`，要求 CPR **3.33.0 或更新的兼容版本**，继续使用 RPC v7。SDK、打包工具与平台目标沿用 1.5

## 修复开启分享后仍没有原生账号模型

- 原生 OAuth 账号从宿主公开的逐账号模型目录取得列表，再按当前 Client Key 的账号及模型权限过滤
- 不使用整站模型目录，不因开启分享而绕过账号黑名单或 Key 范围
- 未提供列表显示「模型未提供」，确实返回空列表才显示「0 个模型」
- 目录失败或超时时保留已有额度，返回可选 `modelsError` 说明原因；关闭模型分享时不返回列表或目录错误
- 单目录最多 1 MiB，一次分享的目录读取共用四秒预算

## 修正额外点数展示

- 原生 credits 标为「额外点数余额」，与 5 小时、周套餐额度区分
- 不导出没有余额且非不限额的空点数记录；下游也隐藏旧版快照中的无有效数据点数行
- 无可用额外点数时不再使用整个账号「额度不可用」的笼统提示

## 升级

上游分享方必须更新到 1.6，才能补齐原生 OAuth 模型列表；只更新下游无法补回未导出的数据。建议上下游同时升级，以显示目录错误及完整模型状态

安装标签 `v1.6.0`，发行目标为 Linux ARM64、Linux x86_64、macOS ARM64，实际附件以 Release 为准
