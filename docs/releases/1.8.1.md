# CPR 数据工具箱 1.8.1

合入 Cline 接入分支，保留 1.7.2 的状态迁移、下游模型权限及界面修复。要求 CPR 3.33.0 或更新的兼容版本，SDK 和打包 CLI 仍锁定到 `8c8618aa`，使用 RPC v7。

## Cline 接入

- 在「Cline 接入」选择账号，将下游 HTTP Responses 转为官方 Cline Chat Completions，并返回 Responses JSON 或 SSE
- 支持文本、图片 URL、完整历史、明文推理、函数工具及结果；完善工具增量、尾部用量和错误帧处理，断流不会冒充成功
- 同页维护 DeepSeek 钉选规则，可修改请求模型名称；缓存规则并减少重复流解析，记录上游明确回报的实际提供方
- 统一各标签页的规则操作、日志、分页与时间格式，继续使用「API密钥」「下游模型权限」等既定文案

## 安装与升级

从 [1.8.1 Release](https://github.com/KazeLiu/cpr-data-toolkit/releases/tag/v1.8.1)选择与宿主进程匹配的 Linux ARM64、Linux x86_64 或 macOS ARM64 附件。ZIP 解压后上传其中的 `.tar.gz`，不要上传外层 ZIP。

1.6.1、1.7.1 和 1.7.2 用户可在原插件实例上升级，不要卸载或清空状态。本版保留 `upstream_quota` schema 2 及 schema 1 → 2 的逐项保留迁移，其他已有 schema 不变；新增独立的 `cline_adapter` 命名空间。

Cline 转换默认不接管任何账号。在「Cline 接入」保存账号选择后，复制实例配置并应用到宿主插件设置，再启用范围匹配且故障策略为 `reject` 的 `upstream` 绑定。已有转换账号升级或修改配置前，先停用相关账号并排空请求，确认配置和绑定后恢复。具体步骤见 [安装说明](../installation.md)。

## 验证范围

发行包通过现有工作流执行前端类型检查、生产构建及三平台后端编译，由锁定的官方 CLI 打包。发布前核对原生架构、资源、版本、官方校验文件与新旧状态声明。

未新增或运行测试，未操作线上宿主。完整工具往返、真实升级、额度与实际提供方仍由用户在目标宿主验收。Cline 转换不支持 `previous_response_id`、WebSocket、加密推理历史、文件引用或 OpenAI 原生/custom 工具。
