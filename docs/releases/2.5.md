# CPR 数据工具箱 2.5

内部版本 `2.5.0`，最低宿主 **CPR 3.40.0**，SDK、UI 依赖与私有状态 schema 不变

## 修复 DeepSeek 1017 区域筛选

- 请求模型为 `deepseek/deepseek-v4.1-flash-1017` 时，命中仅允许 `deepseek` 的启用规则也会附加 `providerOptions.gateway.inferenceRegion`。原有 `cline-pass/deepseek-v4.1-flash-1017` 继续支持，其他模型与未命中请求保持原样
- 不改写请求模型，不用重填已有规则。添加和编辑规则时，可参照输入示例或从日志复制完整请求模型名称

## 升级与核对

提供 Linux ARM64、Linux x86_64 与 macOS ARM64 包。解压 ZIP 后，在原插件实例上传对应的 `.tar.gz` 升级，不要卸载或清空状态

升级后发起新请求，刷新「转换与钉选日志」。命中上述条件的请求应显示「已附加区域筛选」，详情中的「已应用路由参数」可查看 `inferenceRegion`，实际来源以「上游来源信息」为准
