# 工具箱页面统一

## 当前源码的呈现方式

以「Cline 接入」为基础统一全部标签页，不改变请求转换、调度、权限、统计和导入的数据合同。相关修改已包含在 1.9 Linux ARM64 测试包中。

- 页面不展示请求 ID、尝试序号、操作 ID 或请求核对候选的内部编号；这些值仍用于后端关联、去重、恢复和表格键，不从接口或状态中删除
- 取消全部折叠入口，查询设置、配套身份头、验证范围、来源口径、判重证据、目录失败和同步结果直接展示；保留标签页、弹窗、分页与滚动容器
- 页面按实际功能分区使用相同边框、留白、标题层级；表格行内操作使用小号文字按钮，表格外的读取、日志与分页操作使用普通按钮
- 新规则使用「添加规则」，已有规则使用「编辑」「删除」，对应弹窗使用「添加规则」「编辑规则」「删除规则」；持久保存使用「保存规则」，只加入本地编辑列表的操作保留其草稿含义
- 读取已保存配置使用「重新读取」，读取日志使用「刷新日志」，删除日志使用「清空日志」；获取上游数据仍保留「刷新额度」「获取模型列表」等具体对象，不把读取配置与上游查询混为一谈
- 已命中或来源匹配使用宿主绿色语义色，未命中保持普通文字；规则读取失败、真正的调用错误和风险提示保留相应提示，普通保存或复制反馈使用次要文字
- 分页复用 `TablePagination.vue`，统一为「上一页、当前范围 / 总量、下一页」，各页面保留原有页大小与查询入口
- 最近请求、额度更新时间统一用 `dates.ts` 的中文 24 小时格式，仍按浏览器本地时区显示；用量导入的来源时区与日期口径不变

## 保留有意义的术语区分

| 文案 | 使用范围 |
| --- | --- |
| 请求模型名称 | 请求日志与请求匹配规则；Cline 钉选和优先级匹配 CPR 映射后的 model，模型 UA 读取中间件入口模型 |
| 下游模型名称 | Client Key 权限与其可见目录 |
| 计价模型名称 | 定价键，不替换为上游响应中返回的名称 |
| 社区模型名称 | 社区价目的来源标识，写入时仍可调整目标计价名称 |
| 上游来源信息 | Cline 网关明确回报的模型服务提供方，不等于 CPR 账号 Provider 或请求中的模型名 |
| Client Key | 下游访问 CPR 的 Key；上游账号凭据仍称 API Key / Cline Key |

## 本轮核对

已静态核对各页面分页事件、页大小、请求调用和展示字段，并检查折叠入口、内部编号及旧文案的残留。1.9 的前端类型检查与生产构建、ARM64 后端编译和包内资源检查通过。未启动页面或运行测试；完整布局和交互仍待用户在目标宿主确认。
